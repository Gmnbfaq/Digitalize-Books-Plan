## 良序原理

每个非空的非负整数集合都有一个最小元素。

这个命题被称为良序原理(The Well Ordering Principle)。你相信它吗？看起来似乎理所当然，对吧？但请注意它有多么严密：它要求是非空集合——对空集它是假的，因为空集没有任何元素，因而不存在最小元素。它还要求是非负整数集合——对负整数集合它是假的，对某些非负有理数集合也是假的，例如正有理数集合。所以，良序原理捕捉到了非负整数的一些特殊性质。

虽然良序原理看起来显而易见，但很难一眼看出它有什么用处。但事实上，它提供了离散数学中最重要的证明规则之一。在本章中，我们将用几个简单的例子来展示这种证明方法的力量。

## 2.1 良序证明

其实，我们在证明 $\sqrt{2}$ 是无理数时，就已经把良序原理视为当然。那个证明假定：对任意正整数 m 和 n，分数 $m/n$ 都能写成最简形式，即 $m^{\prime}/n^{\prime}$ 的形式，其中 $m^{\prime}$ 和 $n^{\prime}$ 是没有公共素因子的正整数。我们怎么知道这总是可能的？

假设与此相反，存在正整数 m 和 n，使得分数 $m/n$ 不能写成最简形式。令 C 为这类分数的分子组成的正整数集合。那么 $m \in C$，所以 C 非空。因此，由良序原理，必存在一个最小整数 $m_{0} \in C$。于是由 C 的定义，存在整数 $n_{0} > 0$，使得

分数 $\frac{m_{0}}{n_{0}}$ 不能写成最简形式。

这意味着 $m_{0}$ 和 $n_{0}$ 必有公共素因子 $p > 1$。但

$$
\frac{m_{0}/p}{n_{0}/p} = \frac{m_{0}}{n_{0}},
$$

所以把左边的分数写成最简形式的任何方式也适用于 $m_{0}/n_{0}$，这意味着

分数 $\frac{m_{0}/p}{n_{0}/p}$ 同样不能写成最简形式。

于是由 C 的定义，分子 $m_{0}/p$ 属于 $C$。但 $m_{0}/p < m_{0}$，这与 $m_{0}$ 是 $C$ 的最小元素相矛盾。

既然 C 非空的假设导致矛盾，那么 C 必为空。也就是说，不存在不能写成最简形式的分数的分子，因而根本不存在这样的分数。

我们其实从一开始就在暗中使用良序原理了！

## 2.2 良序证明的模板

更一般地，有一种用良序原理证明某个性质 $P(n)$ 对每个非负整数 n 都成立的标准方法。下面是组织这样的良序证明的标准方式：

用良序原理证明"$P(n)$ 对所有 $n \in \mathbb{N}$ 为真"：

定义使 P 为假的反例集合 C。具体地，定义

$$
C ::= \{ n \in \mathbb{N} \mid \text{NOT}(P(n)) \text{ is true} \}.
$$

（记号 $\{ n \mid Q(n) \}$ 表示"所有使 $Q(n)$ 为真的元素 n 组成的集合"。见第 4.1.4 节。）

✏ 为了用反证法证明，假设 C 非空。

由良序原理，$C$ 中必有一个最小元素 n。

设法推出矛盾——通常通过证明 $P(n)$ 实际上为真，或证明 C 中还有比 n 更小的元素。这是证明任务中最开放的部分。

结论：C 必为空，即不存在反例。
## 2.2.1 整数求和

让我们用这个模板来证明

**定理 2.2.1。**

$$
1 + 2 + 3 + \cdots + n = n(n+1)/2\tag{2.1}
$$

对所有非负整数 n 成立。

首先，我们最好先处理两个容易产生歧义的特殊情形，免得它们给我们添乱：

如果 $n = 1$，那么求和中只有一项，所以 $1 + 2 + 3 + \cdots + n$ 就是项 1。不要被 2 和 3 的出现所误导，也不要以为 1 和 n 是不同的项！

如果 $n = 0$，那么求和中一项也没有。按惯例，这种情况下和为 0。

所以，尽管三个点的记号——称为省略号(ellipsis)——很方便，但你必须警惕这些记号具有误导性的特殊情形。事实上，每当你看到省略号时，都应该留心确保自己理解了其中的模式，注意它的开头和结尾。

我们可以用求和记号改写（2.1）的左边，从而免去猜测的麻烦：

$$
\sum_{i=1}^{n} i \qquad \mathrm{or} \qquad \sum_{1 \leq i \leq n} i .
$$

这两个表达式都表示：当变量 i 从 1 取到 n 时，sigma 右边表达式所取的一切值之和。两个表达式都清楚地说明了当 $n = 1$ 时（2.1）的含义。第二个表达式清楚地表明当 $n = 0$ 时和中没有任何项，不过你仍然需要知道这样的惯例：没有数字的和等于 0（顺便说一句，没有数字的积等于 1）。

好，回到证明：

**证明。** 用反证法。假设定理 2.2.1 是假的。那么，某些非负整数是它的反例。让我们把它们收集成一个集合：

$$
C ::= \{ n \in \mathbb{N} \mid 1 + 2 + 3 + \cdots + n \neq \frac{n(n+1)}{2} \}.
$$

假设存在反例，那么 C 是一个非空的非负整数集合。因此，由良序原理，C 有一个最小元素，我们称之为 c。也就是说，在非负整数中，c 是方程（2.1）的最小的反例。

由于 c 是最小的反例，我们知道（2.1）对 $n = c$ 为假，但对所有非负整数 $n < c$ 为真。但（2.1）对 $n = 0$ 为真，所以 $c > 0$。这意味着 $c - 1$ 是一个非负整数，并且由于它小于 $c$，（2.1）对 $c - 1$ 为真。也就是说，

$$
1 + 2 + 3 + \cdots + (c-1) = \frac{(c-1)c}{2}.
$$

但接着，两边加上 c，我们得到

$$
1 + 2 + 3 + \cdots + (c-1) + c = \frac{(c-1)c}{2} + c = \frac{c^{2} - c + 2c}{2} = \frac{c(c+1)}{2},
$$

这意味着（2.1）对 $c$ 竟然真的成立！这是矛盾，于是我们完成了证明。⌅

## 2.3 分解为素数之积

我们此前一直把素数分解定理(Prime Factorization Theorem)视为当然，它也叫唯一分解定理和算术基本定理，说的是：每个大于 1 的整数都有唯一的<sup>1</sup>素数乘积表达式。这又是一条熟悉但仔细审视后并非真正显然的数学事实。我们将在后面的章节中证明素数分解的唯一性，但良序原理可以轻松证明：每个大于 1 的整数都能表示为某个素数乘积。

**定理 2.3.1。** 每个大于 1 的正整数都可以分解为素数之积。

**证明。** 证明采用良序原理。

令 C 为所有大于 1 且不能分解为素数之积的整数的集合。我们假设 C 非空并推出矛盾。

如果 C 非空，由良序原理，存在最小元素 $n \in C$。n 不可能是素数，因为素数本身就被认为是一个（长度为 1 的）素数乘积，而这样的乘积不在 $C$ 中。

所以 n 必是两个整数 a 和 b 的乘积，其中 $1 < a, b < n$。由于 a 和 b 都小于 C 中的最小元素，我们知道 $a, b \notin C$。换言之，a 可以写成素数乘积 $p_{1}p_{2}\cdots p_{k}$，而 b 可以写成
